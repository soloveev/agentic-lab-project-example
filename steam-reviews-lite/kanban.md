### v1.0 — Сбор и хранение
- 🤖 Схема SQLite: `games`, `reviews`; скрипт инициализации
- 🤖 Поиск app_id по названию с подтверждением у пользователя
- 🤖 Сбор карточки игры (appdetails): название, дата выхода, разработчик, издатель

- 🤖 Тесты отдельным агентом: парсинг ответов, upsert без дублей
- 🤖 venv, requirements.txt, команды в README
