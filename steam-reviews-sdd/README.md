# Steam Reviews — справочник проекта

Инструмент сбора, кодирования и просмотра отзывов Steam по заданной игре. Правила для агента — в [CLAUDE.md](CLAUDE.md), требования — в [PRD.md](PRD.md), хронология — в [progress.md](progress.md), задачи — в [kanban.md](kanban.md).

## Дерево проекта

```
demo project/
├── CLAUDE.md          # брифинг агенту: процесс SDD, правила, грабли
├── README.md          # этот файл: инвентарь, дерево, стек, команды
├── PRD.md             # требования продукта, версии v1–v3
├── progress.md        # вехи и решения, последняя запись = текущий этап
├── kanban.md          # задачи по версиям: бэклог → следующее → в работе → готово
├── templates/         # шаблоны spec.md / plan.md / tasks.md для новой пачки
├── specs/             # одна папка на пачку: specs/<NN-slug>/{spec,plan,tasks}.md
├── docs/              # справка по спек-ориентированной разработке для агента и пользователя
├── архив/             # стартовый промпт проекта
├── .claude/skills/    # скиллы агента (появятся в v1.x): steam-collect, review-coding
├── src/               # код: сбор, БД, сервер витрины (появится в v1.0)
├── data/              # steam_reviews.sqlite и raw/<app_id>/*.json (появится в v1.0)
├── tests/             # pytest, пишет отдельный агент (появится в v1.0)
└── codebook.md        # кодбук тем и тональности, версионируется (появится в v1.1)
```

Папки, помеченные «появится», создаются в соответствующей пачке. Дерево обновляется при каждом изменении структуры.

## Инвентарь

| Файл / папка | Роль |
|---|---|
| `PRD.md` | Что делаем и зачем, границы v1, критерии готовности, риски |
| `CLAUDE.md` | Процесс SDD и невыводимые правила для агента, ≤ 50 строк |
| `progress.md` | Хронология вех и решений с «почему» |
| `kanban.md` | Задачи и бэклог, сгруппированы по версиям; задачи Димы и агента |
| `templates/spec.md` | Шаблон спецификации пачки: что и зачем, сценарии, требования, вне scope |
| `templates/plan.md` | Шаблон плана: архитектура, файлы, порядок шагов, тесты |
| `templates/tasks.md` | Шаблон списка задач с чекбоксами и статусами |
| `specs/` | Папки пачек; каждая создаётся из шаблонов, когда Дима называет пачку |
| `docs/spec-driven-development.md` | Справка по SDD: идея, цепочка PRD → Spec → Plan → Tasks → Code, как устроено у нас и в Spec Kit / Kiro / Tessl, чеклисты |
| `архив/first prompt.md` | Стартовый промпт проекта с шаблоном PRD |

## Стек и принципы

- Python 3.12+, виртуальное окружение `.venv/`, зависимости в `requirements.txt` (появится в v1.0).
- SQLite как единственное хранилище. FastAPI + Jinja2 / vanilla JS для витрины.
- Сбор — публичные эндпоинты Steam без ключа: `store.steampowered.com/api/appdetails?appids=<id>` для карточки, `store.steampowered.com/appreviews/<id>?json=1` с курсорной пагинацией для отзывов.
- Кодирование — агент Claude Code по скиллу и кодбуку, батчами, без внешних LLM API.
- Тесты — pytest, пишет и запускает отдельный агент.

## Процесс работы над пачкой

1. Дима называет пачку (например «v1.0 сбор»).
2. Агент создаёт `specs/<NN-slug>/` из `templates/`, пишет `spec.md`, показывает.
3. После одобрения — `plan.md`, `tasks.md`, задачи зеркалятся в `kanban.md`.
4. Реализация по задачам; тесты — отдельным агентом.
5. Закрытие: запись в `progress.md`, обновление README и канбана.

Подробно процесс описан в CLAUDE.md, раздел «Процесс».

## Команды

Появятся в v1.0: создание venv, установка зависимостей, запуск сбора, запуск сервера, запуск тестов.
